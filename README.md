# Бронирование столика в ресторане

Страница онлайн-бронирования столика с формой
и экраном подтверждения.

Live-демо: [HERE](https://booking-taupe-six.vercel.app/)

## Стек

- **Next.js 16**
- **React 19**
- **TypeScript**
- **SCSS Modules**
- **ESLint 9**

## Запуск

```bash
# клонировать репозиторий
git clone https://github.com/Nelson1o/booking.git

# установить зависимости
npm install

# запустить dev-сервер
npm run dev
```

## Что можно доделать

### Функциональность

- **Реальный API.** Заменить `setTimeout` на `fetch` к бэкенду, добавить обработку сетевых ошибок и `try/catch`.
- **Маска телефона.** Автоматическое форматирование при вводе.
- **Список занятых слотов.** Скрывать время, уже забронированное другими гостями.
- **Больше слотов времени** — с шагом 30 минут, а не только
  целые часы.

### Архитектура

- **Отдельные маршруты** `/booking` и `/confirmation` вместо
  переключения состояний.
- **URL-состояние** через `searchParams`.

### Качество

- **Тесты.** Юнит-тесты для функций из `lib` (Vitest).
- **Анимации** появления карточек.
- **Тёмная тема** через `data-theme` и `localStorage`.
